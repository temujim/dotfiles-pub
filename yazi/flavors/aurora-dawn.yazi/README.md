## 🎨 Installation

### Using package manager

```bash
ya pkg add kshawkat/aurora-dawn
```

### Manual install

```bash
# Linux/macOS
git clone https://github.com/kshawkat/aurora-dawn.yazi.git ~/.config/yazi/flavors/aurora-dawn.yazi

# Windows
git clone https://github.com/kshawkat/aurora-dawn.yazi.git %AppData%\yazi\config\flavors\aurora-dawn.yazi
```

## ⚙️ Usage

Add the these lines to your `theme.toml` configuration file to use it:


```toml
[flavor]
use = "aurora-dawn"
# For Yazi 0.4 and above
# switch between light and dark automatically based on terminal settings
dark = "aurora-storm"
light = "aurora-dawn"
```
