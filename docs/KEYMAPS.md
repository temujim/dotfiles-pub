# Consolidated Keymap Reference (mac terminal/agentic stack)

Compiled 2026-08-10 from the LIVE configs in this repo (the canonical source).
This is a quick reference; the config files themselves are the authority.

---

## TMUX  (prefix = C-a, Ctrl-b unbound)
Source: home/.tmux.conf

| Keys | Action |
|------|--------|
| C-a | prefix |
| C-a C-a | send a literal Ctrl+A to the pane app |
| prefix h / j / k / l | select pane Left / Down / Up / Right |
| prefix H / J / K / L | resize pane Left/Right 10; Down/Up 5 (repeatable while held) |
| prefix P | paste tmux buffer |
| prefix C-s | SAVE session (tmux-resurrect) |
| prefix C-r | RESTORE session (tmux-resurrect) |
| C-h / C-j / C-k / C-l (no prefix) | smart pane switch: if pane runs vim/neovim/fzf, send the key to the app; else move across tmux panes |
| C-\ | (copy-mode/if-shell) jump to last pane |
| copy-mode (prefix `[`) | vi mode; Space=begin select, v/Enter/y/copy; mouse-drag-end copies too |
| copy-mode Enter or y | copy selection to macOS clipboard (pbcopy) and cancel |
| Mouse | on (scroll = copy-mode history, drag = select+copy) |

Modes: `mode-keys vi`, `escape-time 0`, `aggressive-resize on`,
`default-terminal screen-256color`, `set-clipboard on` + `allow-passthrough on`.
Panes borders: `double` (═) + bold (colour236 normal / colour148 active).
Status bar is generated by tmuxline.vim into ~/.tmux-status.conf (don't edit by hand).

## ZSH / TERMINAL (vi-mode line editing + autocomplete stack)
Source: home/.zshrc

| Mode | Key | Action |
|------|-----|--------|
| insert | Tab | command/path completion |
| insert | Right Arrow | accept gray inline autosuggestion (whole line) |
| insert | Ctrl-F | accept autosuggestion (home-row alternative) |
| insert | Ctrl-R | fzf fuzzy HISTORY search |
| insert | Ctrl-T | fzf FILE picker → insert selected path |
| insert | Alt-C | fzf DIRECTORY jumper → cd into selected dir (subdirs of cwd) |
| insert | Esc | switch to vi NORMAL mode |
| normal | i / a / A | back to INSERT (i=here, a=append, A=end of line) |
| normal | h l b w 0 $ j k | vi motion / line editing / history browse |
| normal | u | undo |
| normal | Ctrl-T | redo |
| normal | Ctrl-R | history search (fzf) |
| — | — | cursor shape: block=NORMAL, beam=INSERT, underline=REPLACE |

Ordering in .zshrc matters: completions → compinit -u → fzf → autosuggestions
→ vi block → KEY-FIX block (re-binds ^R to fzf, ^F to forward-char) →
zsh-syntax-highlighting LAST.
Terminal prerequisite: Option-as-Meta ON (Basic profile) so Alt-C sends ESC-prefix.
PATH-first: `~/.local/bin` shadows brew binaries (e.g. fzf 0.74.1).

## NVIM  (mapleader = Space)
Source: nvim/init.lua

| Keys | Action |
|------|--------|
| Space e | toggle file explorer (nvim-tree) — VS Code left sidebar |
| Space E | reveal current file in explorer |
| Space e f | open explorer rooted at the current file's folder (agentic favorite) |
| `-` / `<C-]>` / `Ctrl-w h` `Ctrl-w l` | explorer up / jump / window nav |
| Space m v | toggle Markdown raw ⇄ rendered (Obsidian-like) |
| Space w h / l / j / k | resize current window narrower / wider / shorter / taller |
| Space w `=` | equalize window sizes |
| Space w `\|` / `_` | maximize current window width / height |
| Space w f w / f h / f a | toggle winfixwidth / winfixheight / both (lock) |
| y p | copy current buffer's absolute path to macOS clipboard |
| Space w s / r / d | nvim session Save / Load / Delete (auto-save on quit) |

Plugins: lazy.nvim (bootstrap), nvim-treesitter, render-markdown.nvim,
nvim-tree.lua (+ web-devicons), obsidian.nvim. `termguicolors` on;
Markdown buffers render like Obsidian by default, editable in place.

## CLAUDE CODE CLI  (editorMode = vim)
Source: apps/claude/settings.json + keybindings.json

| Keys | Action |
|------|--------|
| ctrl+t | toggle todos |
| ctrl+o | toggle transcript |
| ctrl+r | history search |
| ctrl+l | clear input |
| ctrl+x ctrl+k | kill agents |
| shift+tab | cycle chat mode |
| meta+p / meta+o / meta+t | model picker / fast mode / thinking toggle |
| ctrl+j or alt+enter | newline |
| ctrl+_ | undo |
| ctrl+s | stash |
| ctrl+v | paste image |
| editorMode: vim | vim input mode |
| model: opus, tui: fullscreen | default model + fullscreen TUI |

(Full binding table incl. transcript/scroll/diff contexts is in
apps/claude/keybindings.json — kept verbatim.)
